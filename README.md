# Research Internship Project: Explainable Paediatric Wrist-Fracture Assessment

This project is the first part of Zhi Yu's one-year research intern output in PeRCeiVe Lab at University of Catania (Oct 2025 - Oct 2026).

code copy for cpu version on window surface 7 device, 25.03.2026

Used public dataset: GrazPedWri-Dx paediatric wrist-radiograph dataset

Dataset link: https://www.kaggle.com/datasets/jasonroggy/grazpedwri-dx

Main Contributions:

• Developed a fracture-classification pipeline using the GrazPedWri-Dx paediatric wrist-radiograph dataset, including
preprocessing, augmentation, and class-imbalance handling.

• Combined CNN-based classification with Grad-CAM, Integrated Gradients, and MedCLIP prompt matching to provide
spatial and semantic explanations for model predictions.
